# BLACKOUT 2049 – Mathe-Escape-Game

**Erstellt von Jutta Aeckersberg mit ChatGPT**

In der futuristischen Stadt NOVA ist die Energieversorgung zusammengebrochen. In drei Missionen stellen die Spielenden das Energienetz, das Funknetz und das Kontrollzentrum wieder her. Dabei erschließen sie sich spielerisch das Gleichsetzungs-, Einsetzungs- und Additions-/Subtraktionsverfahren für lineare Gleichungssysteme mit zwei Unbekannten. Mit jeder erfolgreich abgeschlossenen Mission kehrt das Licht in die Stadt zurück.

Das Escape-Game ist **vollständig im Browser spielbar** – ohne Installation, Anmeldung oder Internetverbindung. Spielstände können gesichert und später wiederhergestellt werden. Zum Abschluss lassen sich die Rechenwege als PDF speichern.
